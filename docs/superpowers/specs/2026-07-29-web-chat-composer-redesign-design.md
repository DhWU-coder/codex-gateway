# Web Chat 输入框视觉改造设计

## 目标

将 Web Chat 当前横向拥挤的单排输入框改成接近 Codex App 的双层创作区：上层用于多行文本，下层承载附件入口、模型配置和发送或停止操作。保留现有命令、引用、附件和运行参数能力。

## 布局

- 输入框整体使用一个统一表面和边框，不再让文本区呈现独立表单边框。
- 文本区位于上层并占满宽度，桌面端提供更舒展的默认高度，同时继续支持随内容自动增高。
- 底部操作栏左侧仅保留“添加上下文”按钮。
- 底部操作栏右侧依次放置模型配置摘要和圆形发送按钮。
- 任务运行时，发送按钮原位替换为圆形停止按钮，布局不跳动。
- 待发送附件和引用仍显示在输入框上方，命令、引用和模型菜单仍从输入框上方弹出。

## 视觉

- 外壳采用比页面背景略亮的表面色、柔和边框和轻量阴影。
- 边角比现有输入框更圆润，但保持与产品其他控件协调。
- 文本区聚焦时高亮整个输入框外壳，不单独绘制输入焦点框。
- 发送按钮使用白色圆形背景和深色发送图标；禁用时降低对比度。
- 停止按钮保持危险语义，但使用同尺寸圆形按钮。
- 模型摘要继续显示具体模型、Effort 和速度，不回退成“默认”文案。

## 响应式

- 桌面端输入框默认高度约 116px，文本区和操作栏上下分层。
- 移动端降低默认高度和内边距，底部操作栏保持单行。
- 模型摘要在窄屏中限制宽度并省略溢出内容，发送按钮尺寸保持稳定。

## 行为边界

- 不修改消息提交、停止任务、上传文件、拖拽、粘贴、`/` 命令或 `@` 引用逻辑。
- 不新增语音、自定义模式或其他图 2 中存在但当前产品没有的功能。
- 不修改后端接口、会话数据或账户配置。

## 测试

- 页面结构测试验证双层布局容器、文本区和底部操作栏的层级。
- 样式测试验证输入框最小高度、统一聚焦态、圆形发送按钮和移动端规则。
- 运行 Web Chat 页面测试、全量单测、类型检查和构建。
- 在桌面与移动视口检查输入区尺寸、对齐、弹层锚点及文本不溢出。
