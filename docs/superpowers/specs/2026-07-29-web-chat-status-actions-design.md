# Web Chat 状态与操作按钮设计

## 目标

修复 Web Chat 顶部运行状态被挤成竖排的问题，并让分支、删除、账户、主题和退出操作无需猜测即可理解。保持现有聊天布局、交互流程和明暗主题，不改动任何 Session 或认证行为。

## 状态标签

顶部运行状态从复用 `.status-dot` 的固定 8px 圆点改为独立的 `.run-status` 标签。标签由状态圆点和单行文字组成：

- 空闲时显示灰色圆点和“就绪”；
- 运行时显示强调色圆点和“运行中”；
- 标签使用稳定高度、自动宽度和 `white-space: nowrap`，不得因标题或运行参数变化而竖排或改变头部高度；
- `aria-label` 与可见文字同步，保证辅助技术能够读取当前状态。

会话列表中的小圆点继续使用现有 `.status-dot`，不受本次改动影响。

## 操作按钮

使用本地 `lucide` 包中的图标，不加载 CDN：

- `GitFork`：分支；
- `Trash2`：删除；
- `UserRound`：账户；
- `Sun` / `Moon`：主题；
- `LogOut`：退出。

桌面端显示“图标 + 中文标签”。删除按钮使用危险色，其余按钮保持中性。按钮继续保留 `title` 和 `aria-label`，并增加 CSS Tooltip；当响应式布局隐藏文字时，鼠标悬浮或键盘聚焦仍能看到操作名称。

侧栏底部改为两行：第一行显示当前用户名，第二行放置账户、主题和退出三个等宽按钮。顶部的分支和删除保持在标题栏右侧。

## 响应式行为

- 宽屏显示所有中文标签；
- 中等宽度下运行参数收进现有弹出面板，同时隐藏顶部操作按钮文字，只保留图标和 Tooltip；
- 移动端侧栏中的账户、主题和退出按钮隐藏文字，只保留标准图标、`title`、`aria-label` 和 Tooltip；
- 所有按钮尺寸固定，文字隐藏或状态变化时不得造成头部、侧栏底部或消息区域跳动。

## 图标渲染

新增 Web Chat 专用图标渲染模块，只接收 Lucide 的 `IconNode` 并输出固定属性的 SVG。渲染器转义标签属性值，SVG 使用 `currentColor`、`aria-hidden="true"` 和 `focusable="false"`；按钮本身承担可访问名称。

主题切换不再覆盖按钮内容。页面同时渲染太阳和月亮图标，通过当前主题类切换可见图标，并同步更新按钮的 `title`、`aria-label` 和 Tooltip 文案。

## 测试与验证

- 页面单元测试验证状态标签结构、中文按钮标签、Lucide SVG、危险操作样式和可访问名称；
- 页面脚本测试验证运行状态只更新标签文字与状态类，不把状态容器改回 `.status-dot`；
- 页面脚本测试验证主题切换不会使用 `textContent` 覆盖图标；
- 执行 Web Chat 页面测试、全量测试、类型检查和生产构建；
- 重启本地 Gateway 后，在桌面与移动视口检查状态不换行、按钮无重叠、明暗主题图标正确切换，现有聊天操作仍可用。
